# E-commerce Completo

Projeto de loja virtual com catálogo, filtro por categoria, busca, carrinho persistente e checkout simulado.

## Tecnologias
- React
- Vite
- LocalStorage
- Componentização
- Responsividade

## Como rodar
```bash
npm install
npm run dev
```

## Como subir no GitHub
```bash
git init
git add .
git commit -m "feat: projeto e-commerce completo"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

## Deploy sugerido
Vercel ou Netlify.
